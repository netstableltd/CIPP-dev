# Community Additions

**Community Additions** collects features contributed by CIPP users that aren't part of CIPP itself. Each one is an **add-on**: a self-contained set of pages and functions with a manifest saying what it is, which CIPP versions it has been tested on and what it uses from CIPP. The installed add-ons are listed in the menu under **Community Additions**.

* [Claude for Microsoft 365](../addons/claude-m365/README.md): set up Anthropic's Claude connector for Microsoft 365 in a tenant, limited to the people you choose.
* [Settings > Add-ons](settings/addons.md): turn add-ons on and off, check them against this CIPP version, and upload or download add-on packages.
